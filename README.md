# roblox-reshade-preset
Beautiful and realistic ReShade preset for Roblox.
# 🌟 Автоматический установщик пресета RoShade для Roblox

Мой кастомный графический пресет для **RoShade**, оформленный в виде удобного автоматического установщика. Программа сама найдет нужные директории и настроит графику для вашей игры. Он делает картинку более сочной, добавляет реалистичные тени и сглаживание.

## 🛠️ Как установить

Вам больше не нужно вручную переносить файлы в папки программы! 

### Пошаговая инструкция:
1. Перейдите в блок **Releases** (Релизы) на правой панели этой страницы и скачайте актуальный `.exe` файл (или скачайте его из списка файлов выше).
2. Запустите скачанный файл установщика на вашем компьютере.
3. Следуйте простым подсказкам мастера установки.
4. После завершения процесса запустите Roblox.
5. Нажмите клавишу **F8** (или **Home**), чтобы открыть меню RoShade, и выберите установленный пресет в верхнем списке.

## ⚠️ Важное примечание для пользователей Windows
Так как данный установщик является новой и созданной вручную программой, фильтр **SmartScreen (Защитник Windows)** или сторонние антивирусы могут выдать предупреждение о «неизвестном издателе» при запуске `.exe`. 
- Это **стандартное поведение безопасности** Windows для всех новых независимых программ без платной цифровой подписи.
- Чтобы запустить установщик, нажмите кнопку **"Подробнее"** в окне предупреждения, а затем — **"Выполнить в любом случае"**.
